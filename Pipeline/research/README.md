# What each feature was built from

One file per feature, written before the code: the references, the proven open work, and the shapes read off them. Start here before changing a feature, so the reasoning isn't redone. Named films and games stay out of this repo.

- `FLIGHT_SOURCES.md`: turbine jets, flight, hover, takeoff.
- `FIRE_SOURCES.md`: flame, the fire kit, the fighting styles, usable motion capture.
- `BEACH_SOURCES.md`: shore bands and dune grass.
- `WORLD_SOURCES.md`: sunken buildings, the shape grammar, lava, bosses.
- `SMOOTH_SOURCES.md`: smooth movement, the mixer's write rule, the look, frame pacing.
